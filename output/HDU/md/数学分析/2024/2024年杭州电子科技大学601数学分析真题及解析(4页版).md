5.求 $x ^ { 2 } + y ^ { 2 } + z ^ { 2 } = 6$ 与 $x ^ { 2 } + y ^ { 2 } = z$ 的交线的切线方程.

联立方程 $x^2+y^2+z^2=6$ 与 $x^2+y^2=z$，得到 $z^2+z-6=0$。由于 $z=x^2+y^2\geq0$，所以交线满足 $z=2$、$x^2+y^2=2$。可取参数方程 $x=\sqrt2\cos t$、$y=\sqrt2\sin t$、$z=2$。在交线上任一点 $(x_0,y_0,2)$，切向量为 $(-y_0,x_0,0)$，切线方程可写为

$$
\begin{cases}
x_0x+y_0y=2,\\
z=2.
\end{cases}
$$

本段由助手依据原方程及可识别的参数解法整理，消除了识别稿中损坏的括号。
