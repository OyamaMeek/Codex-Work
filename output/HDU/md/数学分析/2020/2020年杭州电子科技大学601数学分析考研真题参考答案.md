1. 求 $\lim_{n\to\infty}\sum_{k=1}^n\frac{k}{n^2+n+k}$。

【OCR公式整理】记和为 $S_n$，则
$$
\frac{n(n+1)}{2(n^2+2n)}
\le S_n\le\frac{n(n+1)}{2(n^2+n+1)}.
$$
两端均趋于 $1/2$，故答案为 $1/2$。题目末尾误识的 $0$ 与夹逼证明不符，已据此核正。

5. 已知 $f(x)=\int_1^x\sqrt{1+t^4}\,dt$，求 $\int_0^1x^2f(x)\,dx$。

## 二.计算题（本大题共5小题，每小题6分，共30分)

1. 求原题对数极限。

【OCR括号整理】按原参考解答的化简过程，分子为 $\ln((1+x)^{1/x})-1$，故
$$
\frac{\ln((1+x)^{1/x})-1}{\ln(1+x)}
=\frac{\ln(1+x)-x}{x\ln(1+x)}
\longrightarrow-\frac12.
$$
原识别的幂与 $\ln$ 的结合范围含混，此处给出与原推导一致的括号；若原稿采用不同括号，须另行核对。

2. 计算 $\int_{-2}^2\min\{1/|x|,x^2\}\,dx$。

【OCR公式整理】被积函数为偶函数，$|x|\le1$ 时取 $x^2$，$1\le|x|\le2$ 时取 $1/|x|$。所以
$$
2\int_0^1x^2\,dx+2\int_1^2\frac{dx}{x}=\frac23+2\ln2.
$$
零点处按连续延拓取值，不影响积分。

3.设 $z = z ( x , y )$ 为方阵 $f ( x - y , y - z , z - x ) = 0$ 所确定的隐函数，求 $\frac { \partial z } { \partial x } , \frac { \partial z } { \partial y }$ 和dz.

## 【宝哥解答】

【OCR公式整理】令 $G(x,y,z)=f(x-y,y-z,z-x)$，各 $f_i$ 均在该复合自变量处取值。由链式法则，
$$
G_x=f_1-f_3,\quad G_y=-f_1+f_2,\quad G_z=-f_2+f_3.

在 $f$ 连续可微且 $f_3-f_2\ne0$ 的隐函数条件下，

z_x=-\frac{f_1-f_3}{f_3-f_2},\qquad
z_y=-\frac{-f_1+f_2}{f_3-f_2},\qquad dz=z_x\,dx+z_y\,dy.

1. 关于 $f(x)=|x|^\alpha\sin(1/x)$（$0<|x|\le1$），$f(0)=0$ 的原点导数及导函数性质。

【识读差异待核对】打印答案的计算过程对应第（1）问 $f'(0)$、第（2）问 $f'$ 有界、第（3）问 $f'$ 连续；独立真题OCR将部分一阶导数识为二阶，且正弦自变量另有 $1/|x|$ 的版本。原稿这些符号仍需核对，不能宣称已确定原题的全部导数阶数。以下核定当前参考解答实际讨论的一阶导数版本；$f$ 的分段定义保留本参考稿的 $1/x$。

【OCR公式整理】有
$$
f'(0)=\lim_{h\to0}\frac{|h|^\alpha\sin(1/h)}h.
$$
取振荡峰值子列可见有限极限存在当且仅当 $\alpha>1$，此时为零。
当 $x\ne0$ 时，
$$
f'(x)=\alpha|x|^{\alpha-1}\operatorname{sgn}(x)\sin(1/x)
-|x|^{\alpha-2}\cos(1/x).
$$
因此在包含原点的区间上 $f'$ 有界的充要条件为 $\alpha\ge2$；在原点连续的充要条件为 $\alpha>2$。必要性可取 $x_n=1/(2n\pi)$ 检验余弦项；$\alpha=2$ 时该项振荡，故有界但不连续。若采用 $\sin(1/|x|)$，一阶导数公式的符号需相应改变，但上述三个阈值不变。

3.计算曲面积分 $\check { x } = \int \int \frac { \alpha x d y d z + ( z + a ) ^ { 2 } d x d y } { \sqrt { x ^ { 2 } + y ^ { 2 } + z ^ { 2 } } }$ ，其中Σ为下半球面 $z = - \sqrt { a ^ { 2 } - x ^ { 2 } - y ^ { 2 } }$ 的上侧， $a > 0$ 为常数.

## 【宝哥解答】

£为下半球面 $z = - \sqrt { a ^ { 2 } - x ^ { 2 } - y ^ { 2 } }$ 的上侧， $a > 0$ 为上侧，

$$
\iint \frac { a x d y d z + ( z + a ) ^ { 2 } d x d y } { \sqrt { x ^ { 2 } + y ^ { 2 } + z ^ { 2 } } } = \frac { 1 } { a } \iint a x d y d z + ( z + a ) ^ { 2 } d x d y
$$

下面来计算 $\iint _ { \Sigma } a x d y d z + ( z + a ) ^ { 2 } d x d y$

【OCR公式整理：方法一】设 $\Omega$ 为下半球体，$\Sigma_1$ 为 $z=0$ 的下侧圆盘。题设下半球面的“上侧”指向球体内部，所以 $\Sigma+\Sigma_1$ 为内向闭曲面。对 $\mathbf F=(ax,0,(z+a)^2)$，散度为 $3a+2z$。又
$$
\iint_{\Sigma_1}\mathbf F\cdot\mathbf n\,dS=-\pi a^4,\quad
\operatorname{Vol}(\Omega)=\frac{2\pi a^3}{3},\quad
\iiint_\Omega z\,dV=-\frac{\pi a^4}{4}.
$$
因此
$$
\iint_\Sigma\mathbf F\cdot\mathbf n\,dS
=-\iiint_\Omega(3a+2z)\,dV+\pi a^4
=-\frac{\pi a^4}{2}.
$$
题设分母在球面上恒为 $a$，所以原积分为 $-\pi a^3/2$。

【OCR公式整理：方法二】保留原稿使用投影计算的第二种思路。令
$h=\sqrt{a^2-x^2-y^2}$、$z=-h$，投影盘为 $D:x^2+y^2\le a^2$。上侧曲面积分给出
$$
\iint_\Sigma\mathbf F\cdot\mathbf n\,dS
=\iint_D\left[-\frac{ax^2}{h}+(a-h)^2\right]dx\,dy.
$$
用极坐标逐项计算
$$
\iint_D\frac{x^2}{h}\,dx\,dy=\frac{2\pi a^3}{3},\quad
\iint_Dh\,dx\,dy=\frac{2\pi a^3}{3},\quad
\iint_Dh^2\,dx\,dy=\frac{\pi a^4}{2}.
$$
代回得 $-2\pi a^4/3+\pi a^4-4\pi a^4/3+\pi a^4/2=-\pi a^4/2$，再除以 $a$，与方法一一致。

## 四.证明题(本大题共5小题，每小题10分，共50分)

1.设 $\left\{ a _ { n } \right\}$ 是递增有界正数列，求证：级数 $\sum _ { n = 1 } ^ { \infty } ( 1 - \frac { a _ { n } } { a _ { n + 1 } } )$ 收敛.

## 【宝哥解答】

$\left\{ a _ { n } \right\}$ 是递增有界正数列，由单调有界准则 $\because \{ a _ { n } \}$ 收敛，记其极限为a.

【OCR公式整理】由单调有界性，设 $a_n\to L$，其中 $L\ge a_1>0$。并且
$$
\sum_{k=1}^n(a_{k+1}-a_k)=a_{n+1}-a_1\to L-a_1.
$$
又
$$
0\le1-\frac{a_n}{a_{n+1}}
=\frac{a_{n+1}-a_n}{a_{n+1}}
\le\frac{a_{n+1}-a_n}{a_1}.
$$
比较判别法即得目标级数收敛。

2.设 $f ( x ) = { \frac { x + 2 } { x + 1 } } \sin { \frac { 1 } { x } }$ a>0为常数，试证：f（x）在（0,a）内非一致连续，而在$[ a , + \infty )$ 上一致连续.

## 【宝哥解答】

【OCR公式整理】原稿使用的两个结论为：有限开区间上的连续函数一致连续，当且仅当两端均存在有限单侧极限；半无限区间上的连续函数若在无穷远存在有限极限，则一致连续。

第一个结论的必要性由一致连续定义推出端点 Cauchy 条件，充分性由在两端连续延拓后使用紧区间的一致连续性得到。第二个结论将区间分为紧区间和无穷远尾部，并在连接点附近使用三角不等式即可。

本题 $f(x)=(x+2)(x+1)^{-1}\sin(1/x)$。取
$$
x_n=\frac1{2n\pi+\pi/2},\qquad y_n=\frac1{2n\pi+3\pi/2},
$$
则 $|x_n-y_n|\to0$，而 $f(x_n)\to2$、$f(y_n)\to-2$，故在 $(0,a)$ 不一致连续。另一方面 $f$ 在 $[a,\infty)$ 连续且 $f(x)\to0$，由上述结论在该区间一致连续。

3. 设 $f$ 在 $[0,1]$ 连续、在 $(0,1)$ 可导，$f(1)=0$。证明存在 $\xi\in(0,1)$，使
$$
f(\xi)+(1-e^{-\xi})f'(\xi)=0.
$$
【OCR公式整理】令 $F(x)=(e^x-1)f(x)$，则 $F(0)=F(1)=0$。Rolle 定理给出 $F'(\xi)=0$，而
$$
F'(\xi)=e^\xi f(\xi)+(e^\xi-1)f'(\xi)
=e^\xi[f(\xi)+(1-e^{-\xi})f'(\xi)].
$$
除以 $e^\xi$ 即得结论。原题干遗漏的等号与零、证明中误识的正负号均据此核正。

4. 确定 $g(\alpha)=\int_0^\infty\ln(1+x^3)x^{-\alpha}\,dx$ 的定义域，并证明连续性。

【OCR公式整理】当 $x\to0^+$，被积函数 $\sim x^{3-\alpha}$，零端可积当且仅当 $\alpha<4$；当 $x\to\infty$，被积函数 $\sim3(\ln x)x^{-\alpha}$，无穷远可积当且仅当 $\alpha>1$。故定义域为 $(1,4)$。
任取紧区间 $[s,S]\subset(1,4)$，有
$$
\frac{\ln(1+x^3)}{x^\alpha}\le
\begin{cases}
\ln(1+x^3)/x^S,&0<x\le1,\\
\ln(1+x^3)/x^s,&x\ge1.
\end{cases}
$$
两个控制函数分别可积，故积分在 $[s,S]$ 一致收敛。被积函数关于参数连续，故 $g$ 在该紧区间连续；由其任意性，$g$ 在 $(1,4)$ 连续。

5. 设 $f(x,y)=(x^3+y^3)/(x^2+y^2)$（非原点），$f(0,0)=0$。证明原点连续但不可微。

【OCR公式整理】由
$$
|f(x,y)|\le\frac{x^2|x|+y^2|y|}{x^2+y^2}\le|x|+|y|\to0
$$
得连续。又 $f_x(0,0)=f_y(0,0)=1$，而微分余项商为
$$
\frac{f(x,y)-x-y}{\sqrt{x^2+y^2}}
=-\frac{x^2y+xy^2}{(x^2+y^2)^{3/2}}.
$$
沿 $x=y>0$，此商为 $-1/\sqrt2$，不趋于零，故不可微。
