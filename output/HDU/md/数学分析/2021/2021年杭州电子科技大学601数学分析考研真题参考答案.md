4. 证明 $\int_0^\infty xe^{-\alpha x}\,dx$ 在 $[\alpha_0,\infty)$（$\alpha_0>0$）上一致收敛，但在 $(0,\infty)$ 上不一致收敛。

【OCR公式整理】题面积分由同题后续分部积分式互证恢复。对 $X>0$，
$$
T(X,\alpha)=\int_X^\infty xe^{-\alpha x}\,dx
=e^{-\alpha X}\left(\frac X\alpha+\frac1{\alpha^2}\right).
$$
因此
$$
\sup_{\alpha\ge\alpha_0}T(X,\alpha)
=e^{-\alpha_0X}\left(\frac X{\alpha_0}+\frac1{\alpha_0^2}\right)\to0.
$$
但对任意固定 $X>0$，$T(X,\alpha)\to\infty$（$\alpha\to0^+$），所以
$\sup_{\alpha>0}T(X,\alpha)=\infty$。由一致收敛的尾部判据，结论成立。

5.设f（x）在 $\left[ a , b \right] \left( a < b \right)$ 上连续且单调递增.求证：

$$
\int _ { a } ^ { b } x f ( x ) d x \geq { \frac { a + b } { 2 } } { \int _ { a } ^ { b } f ( x ) d x } .
$$

【宝哥解答】

【OCR整理补全】以下分段积分与换元等式按本题题面及本题末尾已识别的正确等式恢复。记 $c=(a+b)/2$，有

$$
\begin{aligned}
\int_a^b xf(x)\,dx-c\int_a^b f(x)\,dx
&=\int_a^b(x-c)f(x)\,dx\\
&=\int_a^c(x-c)f(x)\,dx+\int_c^b(x-c)f(x)\,dx\\
&=\int_a^c(x-c)f(x)\,dx+\int_a^c(c-x)f(a+b-x)\,dx\\
&=\int_a^c(x-c)\bigl[f(x)-f(a+b-x)\bigr]\,dx.
\end{aligned}
$$

在[a,b]上连续且单调增加，对任意 $x \in \left[ a , { \frac { a + b } { 2 } } \right]$ $a + b - x \geq x$ 故

$f(x)-f(a+b-x)\le0$，且 $x-(a+b)/2\le0$，故
$(x-(a+b)/2)[f(x)-f(a+b-x)]\ge0$，其中 $x\in[a,(a+b)/2]$。因此

$$
\int_a^b xf(x)\,dx-\frac{a+b}{2}\int_a^b f(x)\,dx
=\int_a^{(a+b)/2}\left(x-\frac{a+b}{2}\right)
[f(x)-f(a+b-x)]\,dx\ge0.
$$

即 $\int _ { a } ^ { b } x f ( x ) d x \geq { \frac { a + b } { 2 } } \int _ { a } ^ { b } f ( x ) d x$
