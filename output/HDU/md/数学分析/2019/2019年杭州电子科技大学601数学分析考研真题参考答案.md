4. 曲线 $y=x^4-6x^3+12x^2-x+1$ 的拐点。

【OCR公式整理】$y''=12(x-1)(x-2)$，在 $1,2$ 两侧均改变符号。故拐点为 $(1,7)$、$(2,15)$。

5. 连续函数满足 $2f(x)+x=1+\int_0^1f(x)\,dx$，求该积分。

【OCR公式整理】记 $J=\int_0^1f(x)\,dx$，两端在 $[0,1]$ 积分，得
$2J+1/2=1+J$，所以 $J=1/2$。

6. 设 $F(y)=\int_y^{y^2}\sin(xy)/x\,dx$，求 $F'(y)$。

【OCR公式整理】换元 $u=xy$，有
$$
F(y)=\int_{y^2}^{y^3}\frac{\sin u}{u}\,du,\qquad
F'(y)=\frac{3\sin(y^3)-2\sin(y^2)}y\quad(y\ne0).
$$
若将被积函数在 $x=0$ 连续延拓，则 $F'(0)=0$。

7. 交换 $\int_1^{e^2}dy\int_{\ln y}^2f(x,y)\,dx$ 的积分次序。

【OCR公式整理】区域为 $0\le x\le2,\ 1\le y\le e^x$，所以结果为
$$
\int_0^2dx\int_1^{e^x}f(x,y)\,dy.
$$

1.求极限值 $\lim _ { x  0 ^ { + } } ( \frac { \sin x } { x } ) ^ { \frac { 1 } { x ^ { 2 } } }$

【OCR公式整理】由 $\ln(\sin x/x)=-x^2/6+o(x^2)$，取对数再取指数，所求极限为 $e^{-1/6}$。

$$
y = - y e ^ { x } + 2 e ^ { y } \sin x + 2 x
$$

$$
y ^ { \prime } ( 0 )
$$

【宝哥解答】

令x=0，可得y=0.

令 $F ( x , y ) = y + y e ^ { x } - 2 e ^ { y } \sin x - 2 x$ ，则

$$
F _ { x } ( x , y ) = y e ^ { x } - 2 e ^ { y } \cos x - 2 , F _ { y } ( x , y ) = 1 + e ^ { x } - 2 e ^ { y } \sin x
$$

由隐函数存在定理的结论，有

$$
y ^ { \prime } ( 0 ) = - \frac { F _ { x } ( 0 , 0 ) } { F _ { y } ( 0 , 0 ) } = - \frac { - 4 } { 2 } = 2
$$

3. 设 $f(t)=te^{-t^2}$（$t\ge0$），$f(t)=0$（$t<0$），求 $\int_1^x f(u-1)\,du$。

【OCR公式整理】令 $t=u-1$，分别按积分上限的位置计算：
$$
\int_1^x f(u-1)\,du=
\begin{cases}
0,&x<1,\\
\frac12(1-e^{-(x-1)^2}),&x\ge1.
\end{cases}
$$
原识别在后一分支错误带入的负号由直接求导核定。

4.求级数 $\sum _ { n = 1 } ^ { \infty } n { \frac { 2 ^ { \frac { n } { 2 } } } { 3 ^ { n } } }$ 的和

【OCR公式整理】对 $|t|<1$，几何级数逐项求导给出
$$
\sum_{n=1}^\infty nt^n
=t\left(\sum_{n=0}^\infty t^n\right)'
=\frac{t}{(1-t)^2}.
$$
取 $t=\sqrt2/3$，原数项级数之和为
$$
\frac{\sqrt2/3}{(1-\sqrt2/3)^2}
=\frac{3\sqrt2}{(3-\sqrt2)^2}.
$$

5.计算 $\iint _ { D } ( x + y + 1 ) ^ { 2 } d x d y$ ，其中 $D = \left\{ ( x , y ) \left. 1 \leq x ^ { 2 } + y ^ { 2 } \leq 4 \right. \right\}$

## 【宝哥解答】

【OCR公式整理】环域 $D$ 关于两坐标轴对称，故 $x,y,xy$ 项积分均为零。利用极坐标，
$$
\iint_D(x+y+1)^2\,dx\,dy
=2\pi\int_1^2(r^2+1)r\,dr

## 三.综合题（本大题共3题，每题10分，本大题共30分）

1. 求 $a$，使
$$
f(x,y)=\begin{cases}
(x^2+y^2)^a\cos\frac1{|x|+|y|},&(x,y)\ne(0,0),\\
0,&(x,y)=(0,0)
\end{cases}
$$
在原点可微。

【OCR公式整理】必要性：沿正 $x$ 轴，偏导差商为 $x^{2a-1}\cos(1/x)$。取 $x_n=1/(n\pi)$，若 $a\le1/2$，该差商不能有有限极限。故必须 $a>1/2$。
充分性：此时两偏导均为零，而且
$$
\frac{|f(x,y)|}{\sqrt{x^2+y^2}}
\le(x^2+y^2)^{a-1/2}\to0.
$$
所以所求条件恰为 $a>1/2$。

2. 讨论 $\sum_{n=1}^\infty\frac{(x+1)^n}{(n+1)2^n}$ 的绝对收敛、条件收敛与发散范围。

【OCR公式整理】以 $x+1$ 为变量的收敛半径为 $2$，故在 $-3<x<1$ 绝对收敛。$x=-3$ 时为交错级数，条件收敛；$x=1$ 时为调和型级数，发散。区间外通项不趋于零。因此绝对收敛区间是 $(-3,1)$，条件收敛点是 $-3$，其余点发散。

3.计算曲线积分 $\int _ { L } { \frac { ( e ^ { x } - 2 x y ) d x - ( x ^ { 2 } + y ^ { 2 } ) d y } { ( x - 1 ) ^ { 2 } + y ^ { 2 } } }$ 其中L是在圆周 $y = \sqrt { 2 x - x ^ { 2 } }$ 上由
点O(0,0)到点A(1,1)的一段弧.
【OCR公式整理】圆弧上 $(x-1)^2+y^2=1$，故分母恒为 $1$。原微分形式为
$$
(e^x-2xy)\,dx-(x^2+y^2)\,dy
=d\left(e^x-x^2y-\frac{y^3}{3}\right).
$$
从 $O(0,0)$ 到 $A(1,1)$ 积分，应同时代入两个端点：
$$
\left[e^x-x^2y-\frac{y^3}{3}\right]_{(0,0)}^{(1,1)}
=e-\frac43-1=e-\frac73.
$$

## 四.证明题(本大题共5题，每题10分，本大题共50分)

1.设【OCR公式整理】由单调递减，
$$
a_{n+1}-a_n=f(n+1)-\int_n^{n+1}f(x)\,dx\le0.
$$
又
$$
a_n=f(n)+\sum_{i=1}^{n-1}\left[f(i)-\int_i^{i+1}f(x)\,dx\right]\ge f(n)>0.
$$
所以数列递减且有下界，因而收敛。

2. 设 $f$ 在 $[a,b]$ 二阶可导，图像与端点连线还相交于 $C(c,f(c))$，$a<c<b$。第（1）问要求两侧各有一点导数相等。

【OCR整理及待核对】原题第（2）问在真题和答案OCR中均写为“存在 $f'(\xi)=0$”，但按这一字面结论命题不成立：取 $f(x)=x$ 即为反例。二阶可导条件及原解答对 $f'$ 使用 Rolle 定理的过程支持目标应为 $f''(\xi)=0$；原卷该阶数仍需核对。以下保留并证明可以核算的两个结论。

记端点连线斜率为 $m=(f(b)-f(a))/(b-a)$。共线条件给出
$$
\frac{f(c)-f(a)}{c-a}=\frac{f(b)-f(c)}{b-c}=m.
$$
分别对 $[a,c]$、$[c,b]$ 使用 Lagrange 中值定理，得
$$
\xi_1\in(a,c),\quad\xi_2\in(c,b),\qquad f'(\xi_1)=f'(\xi_2)=m.
$$
再对 $f'$ 在 $[\xi_1,\xi_2]$ 使用 Rolle 定理，得
$\xi\in(\xi_1,\xi_2)$ 满足 $f''(\xi)=0$。这不能推出原OCR所写的 $f'(\xi)=0$。

3. 设 $1<a<b$，证明 $F(x)=\int_e^\infty\cos t/t^x\,dt$ 在 $[a,b]$ 连续且可微。

【OCR公式整理】对于 $x\in[a,b]$，
$$
\left|\frac{\cos t}{t^x}\right|\le t^{-a},\qquad
\left|\frac{\partial}{\partial x}\frac{\cos t}{t^x}\right|
\le\frac{\ln t}{t^a}.
$$
两个控制函数在 $[e,\infty)$ 可积。因此原积分及导数积分均一致收敛，故 $F$ 连续，且
$$
F'(x)=-\int_e^\infty\frac{\cos t\ln t}{t^x}\,dt.
$$

4.设 $\sum _ { n = 1 } ^ { \infty } a _ { n }$ 绝对收敛，证明 $\sum _ { n = 1 } ^ { \infty } a _ { n } ( a _ { 1 } + a _ { 2 } + \cdots + a _ { n } )$ 也绝对收敛.

## 【宝哥解答】

$\sum _ { n = 1 } ^ { \infty } a _ { n }$ 绝对收敛，故 $\sum _ { n = 1 } ^ { \infty } a _ { n }$ 收敛，故其部分和有界，即存在正常数M，使得

对任意正整数n，都有 $\left| a _ { 1 } + a _ { 2 } + \cdots + a _ { n } \right| \leq M$ ，故

$$
\left| a _ { n } ( a _ { 1 } + a _ { 2 } + \cdots + a _ { n } ) \right| \leq M | a _ { n } { \big | } , n = 1 , 2 , \cdots
$$

$\sum _ { n = 1 } ^ { \infty } a _ { n }$ 绝对收敛，故 $\sum _ { n = 1 } ^ { \infty } \left| a _ { n } \right|$ 收敛.由比较判别法， $\sum _ { n = 1 } ^ { \infty } \left| a _ { n } { \big ( } a _ { 1 } + a _ { 2 } + \cdots + a _ { n } { \big ) } \right|$ 收敛.即 $\sum _ { n = 1 } ^ { \infty } a _ { n } ( a _ { 1 } + a _ { 2 } + \cdots + a _ { n } )$ 也绝对收敛.

5.设 $R > 0 ; \Omega$ 为曲面 $z = R ^ { 2 } - x ^ { 2 } - y ^ { 2 }$ 与平面z=0所围成的空间闭区域，Σ为Ω表面的外侧，V为Ω的体积.证明

$$
\iint x ^ { 2 } y e ^ { \sin z } d y d z - x y ^ { 2 } e ^ { \sin z } d z d x + z ( 1 + 2 x y z ) d x d y = V
$$

## 【宝哥解答】

【OCR公式整理】按题面，向量场为
$$
\mathbf F=(x^2ye^{\sin z},-xy^2e^{\sin z},z(1+2xyz)).
$$
其散度为
$$
2xye^{\sin z}-2xye^{\sin z}+1+4xyz=1+4xyz.
$$
立体 $\Omega=\{0\le z\le R^2-x^2-y^2\}$ 关于 $x=0$、$y=0$ 对称，故 $\iiint_\Omega xyz\,dV=0$。由 Gauss 公式，外向通量等于
$$
\iiint_\Omega(1+4xyz)\,dV=\iiint_\Omega1\,dV=V.
$$
