# 大一上工科数学分析模拟卷

本套材料包含期中、期末各3套原创模拟卷及对应解析。范围采用用户确认的安排：期中考极限、连续、导数及应用；期末在此基础上增加一元积分及应用。没有本校大一课程大纲，因此不声称复现某位授课教师的期中或期末命题，也不作押题概率承诺。

## 原卷依据与适用边界

参考对象是本地 `HDU/601数学分析/` 下2022—2026年601考研真题。这些试卷考查整个数学分析课程；本材料只迁移其中适合大一上学期的能力要求，并降低综合跨度。原卷为扫描件，通过本地 OCR 提取两页全文；数学公式的OCR识别不稳定，因此下表只引用可辨认的题型和方向，不转录不确定的公式。2024年为回忆版，题目有缺失。

| 原卷与定位 | 可辨认的方向 | 本材料的转换 |
| --- | --- | --- |
| 2022年原卷第2页，第四大题第1、4题 | 极限定义；构造辅助函数使用中值定理 | 期中A第7、12题训练极限论证与存在唯一性；期中B第12题训练辅助函数 |
| 2023年原卷第1页，填空第2、5题；第2页证明第2题 | 数列极限；间断点；导数中值定理 | 期中各套的极限、分段函数、Rolle定理证明 |
| 2024年回忆版第1页，计算第1题；第2页综合第2、4题 | 未定式极限；连续性及可导性讨论 | 期中B第8题、期中C第8题；不纳入本次未确认的一致连续性专题 |
| 2025年原卷第1页填空及计算；第2页证明第1题、讨论第2题 | 极限与积分；极限定义；分情形讨论连续性、可导性 | 期中基础概念、局部分析，以及期末的积分与分类讨论 |
| 2026年原卷第1页填空与计算第3题；第2页综合第2题 | 极限；高阶导数；数列收敛 | 期中B第5、7题、期中C第7题；期末C第7题 |

原卷中的多元微分、重积分、曲线曲面积分、级数与一致收敛、含参积分不进入本套考试范围。模拟题均为本次新编，不是原卷重排；表中是能力迁移关系，不表示数值题目来自原卷。

## 试卷结构

| 试卷 | 定位 | 重点 |
| --- | --- | --- |
| 期中A | 基础巩固 | 基本极限、递推数列、连续可导条件、求导、函数性质 |
| 期中B | 综合训练 | 高阶导数、导函数连续性、隐函数、对数函数、中值定理 |
| 期中C | 提高训练 | 高阶无穷小、振荡递推、平坦函数、参数方程根数、二阶导数证明 |
| 期末A | 基础巩固 | 不定积分、定积分、变限积分、面积体积、积分中值定理 |
| 期末B | 综合训练 | 分部积分、对称性、含变量上限的积分、Riemann和、积分估计 |
| 期末C | 提高训练 | 积分递推与极限、变限积分局部性质、Newton迭代、含参数绝对值积分、积分不等式 |

每套100分，建议120分钟，闭卷，不使用计算器。填空5题，每题4分；计算与讨论5题，每题10分；证明2题，每题15分。计算题按过程给分，证明题须写出定理适用条件。C卷用于提高，Newton迭代题已给出算法定义。

## 文件与编译

- `模拟试卷.tex`：六套试卷合订本，每套独立起页，题面不含答案，留有答题空间。
- `参考解析.tex`：逐题答案、关键计算步骤和证明；每套附给分建议。
- 两份 `.tex` 均为独立文件，不依赖外部图片、宏文件或网络资源；采用 `ctexart`、`amsmath`、`amssymb`、`geometry`、`enumitem` 和 `fancyhdr`。使用 XeLaTeX 编译，中文字体采用 Fandol。
- 可分别上传到 Overleaf，编译器选择 XeLaTeX；本地安装 TeX Live 后使用 `xelatex 模拟试卷.tex`、`xelatex 参考解析.tex`。

## 练习顺序

按A、B、C顺序限时完成；做完一整套再打开解析。记录错题的知识点、第一处出错步骤及重新解题结果。若尚未学习高阶导数、二阶导数或某种积分技巧，先补相应章节再做相关题。

本套不包含无穷级数、反常积分与微分方程，也不把 Taylor 级数作为作答前提；解析中高阶极限可由反复使用 L'Hôpital 法则或有余项的有限阶展开得到。
