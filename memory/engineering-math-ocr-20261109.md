# 工科数学分析基础上册 Markdown 提取

- 使用本机 PDFium、pypdf、MLX 和 GLM-OCR，沿用上次转换的逐页 Markdown、LaTeX 和原页链接。任务文件及中间识别结果仅在本地保存。
- 以工作区根目录的 PDF 为正文来源。核对同版副本的页序和书签目标后，将其大纲转换为 Markdown 导航。
- 检查全部页的文本层，试跑正文和公式页，分批识别并保存每页结果。复核空白、截断及未配对公式分隔符。
- 交付前检查页码连续性、每个大纲跳转和 PDF 原页链接、原文件 SHA-256 与 Git 忽略范围。

## 运行进度

- 两份 PDF 的 390 页扫描图逐页匹配，当前原件没有文字层和书签，导航取自同版副本的 148 个书签。macOS Vision 已独立识别全部页面。
- GLM-OCR 390 页缓存齐全。`.agent/engineering-math-ocr/` 保存识别、比对和构建脚本，`repairs/` 保存页首公式、分隔符、页边注、表格和识别截断的局部修订。
- `build.py --build` 生成原 PDF 旁的同名 Markdown。390 页均有内容，369 页含公式。检查通过的项目包括公式分隔符、乱码替代字符、连续页码、390 个原页链接、148 个大纲跳转和两份 PDF 各自的 SHA-256。使用 Markdown 解析器核对实际生成的链接和锚点。图表和未逐式校对的公式可通过原页链接回查。
