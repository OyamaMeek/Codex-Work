# 整理这个链接

收到“整理这个链接”和可明确识别的链接后，按以下步骤执行。一次给出多条链接时按用户提供的顺序处理。

1. 打开原链接，读取标题、作者、正文和可访问的配图、表格、引用、代码及提示词。核对折叠和延迟加载的内容。中文文章保留原文。外文文章直接根据原文翻译标题、正文和自然语言提示词，保留代码、命令、公式、变量名和参数。
2. 查找同一原帖 ID 或规范链接的既有归档，有则复用。新文章在本地 `post/` 下续用编号，每篇一个目录。有帖子 ID 时使用 `编号-帖子ID`。在 `文章.md` 写入正文和原帖链接，配图保存到同目录的 `images/` 并相对引用。外文文章另存 `原文.md`。保留图片原样，视频保留可用的封面及原帖播放链接。
3. 读取 [Notion「领域」](https://app.notion.com/p/3c5867d026d980b7bae7c5d3520cbcdb)，确认 `X_post` 的末尾和链接是否已归档。缺失的文章按原顺序追加为同级二级折叠。用中文正文，按原稿保留标题、列表、表格、引用及可复制的代码块。把本地配图上传为 Notion 附件并在正文原位置引用。
4. 核对本地正文和图片引用，再回读 Notion 的插入位置、正文、配图顺序及原样保留的代码。链接、图片或 Notion 暂时不可访问时，继续完成可独立保存的部分，并在回复中说明具体缺口。返回本地 Markdown 和 Notion 页面链接。
