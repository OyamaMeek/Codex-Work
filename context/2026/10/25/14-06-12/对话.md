## 助手
妹妹，在 Copilot Pro 里使用 **Opus 5.5** 一般这样做：

1. 打开支持 Copilot Chat 的客户端（如 VS Code / github.com 聊天）。
2. 进入聊天面板，找到模型选择器（通常是顶部的模型下拉框）。
3. 选择 **Claude Opus 5.5**（如果列表里有）。
4. 直接开始提问即可，该会话就会用 Opus 5.5。

如果你看不到 Opus 5.5，通常是这几种原因：  
- 你的账号/组织还没开通该模型  
- 当前客户端版本太旧  
- 区域或策略限制了可用模型  

你可以先更新客户端并检查 GitHub 的 Copilot 设置页里是否启用了“可选模型/第三方模型”。
